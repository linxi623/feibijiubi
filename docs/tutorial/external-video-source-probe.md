# 外部视频源小规模只读探测：光速候选

状态：目录/详情 API 与一份 HLS 清单可访问，父级复核通过；非浏览器播放或生产接入验收。

## 范围与来源

用户授权从 https://www.ziyuanzu.com/ 选择一个候选进行小规模测试。该首页已获取的部分 HTML 公开列出光速来源及 API：

`https://api.guangsuapi.com/api.php/provide/vod/`

公开收录不等于内容授权。没有导入数据库、运行迁移、启动服务、访问视频切片或密钥、下载视频或修改运行配置。日期以保存响应为准；不是持续监测。

## 父级实测

| 请求 | HTTP | 响应大小 | 耗时 |
|---|---|---|---|
| API `?ac=list` | 200 | 6837 B | 2.957166 s |
| API `?ac=detail&ids=222486`（普通动画分类样本） | 200 | 4604 B | 1.389198 s |
| 第二线路第一集媒体清单 | 200 | 3237 B | 1.738718 s |

API 请求限制连接10秒、总20秒、512KiB；清单64KiB上限，HTTPS校验开启，无自动重定向。媒体请求另做DNS解析结果公网检查并固定一个IPv4连接。该临时探测不是项目HTTP客户端的安全实现；API探测也不构成连接级SSRF防护验收。

子代理只读解析父保存的响应，父再次本地求和和核对关键字段，未重复请求外网。样本在系统临时目录，不提交完整媒体地址、内容、密钥URI或签名参数。

## 已观测结构

- JSON成功码为1；当前列表page/pagecount/total为整数、limit为字符串。适配时有界显式解析，不能假定所有分页字段类型相同。
- API实际Content-Type为text/html;charset=utf-8，但body是JSON。只对明确配置的CMS适配器容忍此偏差，不把任意HTML当数据、不渲染HTML。
- `vod_id=222486`可作为该快照的作品ID；长期稳定性未验证。没有观察到独立稳定episodeId。
- 详情`vod_play_from`与`vod_play_url`按`$$$`分成2条线路，每条20个条目；`#`分集，`$`分集名/地址。命令行中直接写`$$$`曾被shell展开，之后用`chr(36)*3`独立核实，废弃早期错误计数。
- `gsyun`是尚未验证的定位/页面形态；`gsm3u8`第一集已实际获取到HLS媒体清单。不能只凭线路名或扩展名断言其他地址可播放。
- `vod_duration`为空；`vod_total=1`与20条播放条目不一致，不能据此给每集设置时长或集数。
- 单份清单含39个EXTINF与ENDLIST，Decimal求和146.083331秒；是这一集、这一线路、这一份快照的声明时长，不是视频解码验证或其余剧集时长。
- 清单含AES-128 KEY标签；key为相对地址，分片为其它域名的HTTPS地址。本轮均未访问，不验证密钥/分片可达性与解密。
- 清单响应Content-Type为application/vnd.apple.mpegurl，Access-Control-Allow-Origin为*。不代表分片/key具有相同CORS或浏览器可以播放。API请求未携带Origin且未观察到CORS头，不能从该次响应断言所有Origin请求必然失败。

## 父级对研究建议的裁定

1. 接受该站作为首个适配器的**协议样例候选**，不自动加入生产白名单，不批准批量抓取或内容发布。
2. 拒绝子代理“必须用线路名/数组下标合成剧集主键”的建议。这违反已定身份契约，重排会错绑或重复计数。缺少稳定剧集身份仍需持久人工映射或另行批准的匹配协议，不能静默采用位置主键。
3. 清单声明时长可以供管理员核实，但本轮不将它自动写入video.duration，不修改现有互动/进度校验。若未来引入服务端清单时长提取，应是独立、有界、安全校验的切片。
4. Last-Modified等于响应时间并不能证明“不能做任何条件请求”；本轮未测条件请求，暂不依赖其作为可靠增量水位。
5. 后端API出口白名单与浏览器媒体资源域名策略分开。当前后端不代理切片/key，不因清单出现新域名自动扩大服务器允许列表。
6. 选择普通影视分类进行小样本核对，不从全站目录无筛选自动导入；分类过滤不是内容审核的替代品。

## 历史失败与限制

- 首个子代理探测中一个候选连接失败，另一个因成人内容排除；没有请求该成人候选的媒体资源，不纳入接入建议。
- 首个报告工具未给出可核实HTTP状态/耗时/大小，父不接受其“完全可用”或硬请求上限已经验证的表述。
- 当前只有单次目录、单作品、单集清单证据。无持续稳定性、完整播放、内容授权、限额/使用条款、浏览器兼容性证据。
- 尚未实现CMS适配器、剧集绑定、同步任务或播放接口。未改变线上/本地既有业务。
